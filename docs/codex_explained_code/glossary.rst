Glossary
========

.. glossary::

   Observable
      Measured quantity with uncertainty, confidence, timestamp, and source metadata.

   StateVariable
      Estimated latent variable in the twin state hypothesis.

   StateVector
      Structured collection of state variables with covariance.

   Snapshot
      Immutable projection exported for validation and reporting.

   TransitionCandidate
      Intermediate result containing candidate state, modified-entity metadata, and rollback actions.

   Logical immutability
      External immutability guarantees with controlled internal mutation under rollback discipline.

   Contract stratification
      Ordered validation stack: software, temporal, statistical, epistemic, model, hierarchy.
